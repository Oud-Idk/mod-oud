# Docs

Conventions for the Rust bot. `../CONVENTIONS.md` holds the short rules that apply everywhere;
these files hold the ones you read when you touch that part of the system.

| Doc | Read it when |
|---|---|
| [logging.md](logging.md) | Adding, moving, or deleting a log line. Spawning a task, adding an endpoint, choosing a level. |
| [structure.md](structure.md) | Adding a file, a feature, or a module. Deciding where code goes. |
| [database.md](database.md) | Writing or reviewing any `database.rs`, or touching a snowflake. |

The frontend has its own: `../dashboard/CONVENTIONS.md`.
